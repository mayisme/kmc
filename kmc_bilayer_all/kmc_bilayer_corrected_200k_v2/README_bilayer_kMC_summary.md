# Al₂O₃/ZnO 双层阻隔膜 动力学蒙特卡洛（kMC）模拟总结

## 1. 模型概述

使用 **动力学蒙特卡洛（Kinetic Monte Carlo, kMC）** 方法模拟水汽分子穿透 Al₂O₃/ZnO 双层纳米阻隔膜的传输过程。

### 方法特点

- **Rejection-free BKL 算法**：每步无拒绝，按 Arrhenius 速率 `k = ν·exp(-E/kBT)` 选择跳跃方向
- **物理时间尺度**：每步时间 `Δt = -ln(r)/k_total`，可直接输出扩散系数和首次通过时间
- **CUDA 并行**：200,000 个粒子在 GPU 上并行模拟，每个线程独立追踪一个粒子轨迹

### Al₂O₃ 层

- 致密非晶本体：**不可渗透**（跳跃速率 = 0）
- 离散纳米针孔：直径 1–2 nm，间距 50–80 nm，随机分布
- 针孔面积覆盖率：~2.5%

### ZnO 层

- 晶粒本体（纤锌矿结晶）：**不可渗透**（跳跃速率 = 0）
- 晶界网络：Voronoi 多边形，晶粒尺寸 5–10 nm，晶界宽 ~0.5 nm
- 晶界为**唯一扩散通道**，但不直通（20% 晶界被阻断为死端）
- 缺陷错位：针孔与 ZnO 晶界中心偏移 25–50 nm

## 5. 物理解读

水汽穿透 Al₂O₃/ZnO 双层的三道屏障：

1. **Al₂O₃ 针孔筛选**：水汽在表面吸附层扩散，只有找到针孔入口才能进入（针孔覆盖率仅 2.5%）
2. **界面过渡瓶颈**：从针孔出口到 ZnO 晶界入口需要横向扩散，这是最大的动力学瓶颈
3. **ZnO 晶界迷宫**：封闭多边形晶界网络 + 20% 死端阻断，迫使粒子做高曲折度的迂回扩散

**关键发现**：主要瓶颈在 Al₂O₃ 针孔 → 界面 → ZnO GB 入口的过渡。一旦粒子进入 ZnO 晶界网络，几乎都能穿透（仅 0.02% 被困在 ZnO 内）。
